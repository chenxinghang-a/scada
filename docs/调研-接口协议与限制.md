# 可对接的接口：协议、数据格式、接入方式与限制

> 本文件由调研生成，用于指导接口实现与模拟器参数设计。

## 1. Modbus TCP/RTU

| 项 | 内容 |
|---|---|
| 功能码 | 01/02 读位，03/04 读寄存器，05/06 写单个，15/16 写多个，23 读写 |
| 地址 | 线圈0x/离散1x/输入寄存器3x/保持4x；**PDU 用 0-based 偏移**，40001→0 |
| 编码 | 单寄存器 uint16/int16；32 位跨两寄存器，字序 ABCD/CDAB/BADC/DCBA |
| 上限 | PDU 253B；03/04 单次 125 寄存器；01/02 单次 2000 线圈；16 单次 123 |
| 异常码 | 01 非法功能 / 02 非法地址 / 03 非法值 / 04 从站故障 / 06 忙 / 0A 网关 |
| 寻址 | 广播 0 只写不读；单播 1–247 |
| 超时 | 1–3 s，重试 1–2 次；RTU 帧间静默 ≥3.5 字符 |

- **格式**：MBAP 7B（事务2/协议2/长度2/单元1）+ 功能码 + 数据。
- **接入**：TCP 502、RTU 8N1；`pymodbus`（Async 客户端，显式传 slave）。
- **易错**：① 读 126 寄存器直接回异常 03；② **float32 字序真机不统一，模拟器必须可配**；③ 40001 当偏移发；RTU 的 CRC 低字节先发。

## 2. OPC UA

| 项 | 内容 |
|---|---|
| Endpoint | `opc.tcp://host:4840`；策略 None/Basic256Sha256/Aes128 |
| 令牌 | 匿名 / 用户名密码 / X.509（需双向信任） |
| NodeId | `ns=2;i=1001`、`ns=2;s=Tag`；ns0=标准，ns1=服务器自身，**索引随服务器变** |
| 订阅 | Read 用于低频；Subscription 的 PublishingInterval 有下限（100–1000 ms） |
| 采样 | SamplingInterval、DataChangeTrigger、DeadbandValue（仅数值） |
| 队列 | QueueSize 默认 1 会丢中间值，配 DiscardOldest |
| 会话 | SessionTimeout 约 60 s，需 KeepAlive + 重连后**重建订阅** |

- **格式**：二进制 UA（Hello/OpenSecureChannel/CreateSession/Publish）；值带 StatusCode 与双时间戳，**质量看 StatusCode**。
- **接入**：4840；`asyncua`（注意版本 API 破坏性变更）。
- **易错**：① 重连不重建订阅 → 假在线；② 硬编码 ns=2；③ QueueSize=1 致值跳变误判故障。

## 3. IEC 60870-5-104

| 项 | 内容 |
|---|---|
| 帧 | APCI：0x68 + 长度 + 4B 控制域；I 帧（信息）/S 帧（确认）/U 帧（启停、TESTFR） |
| 类型 | M_SP_NA_1(1) 单点、M_ME_NC_1(13) 短浮点、C_SC_NA_1(45) 单点遥控、C_SE_NC_1(50) 设点、C_IC_NA_1(100) 总召、C_CS_NA_1(103) 对时 |
| COT | 3 突发 / 5 被请求 / 6 激活 / **7 确认** / 10 终止 / 20 总召响应 |
| 编址 | 公共地址 2B、IOA 3B（1–16777215，**0 非法**） |
| 参数 | K=12、W=8、t1=15s、t2=10s、t3=20s |
| 总召 | 发 COT=6 → 回 7 → 逐点上送 COT=20 → COT=10 终止 |

- **格式**：类型1 + VSQ1 + COT2 + 公共地址2 + 信息对象；短浮点 IEEE754 **小端**；时标 CP56Time2a。
- **接入**：TCP 2404；`c104`/`pyiec104`，主站主动连从站。
- **易错**：① **K 窗口溢出**（不发 S 确认→卡死）；② IOA 用 0 基址或 2 字节；③ 把 COT=7 当数据入库。

## 4. MQTT

| 项 | 内容 |
|---|---|
| QoS | 0 可能丢；1 至少一次（**会重复，需幂等**）；2 恰好一次（开销大） |
| retained | 保留最后一条；清除需空 payload + retain=1 |
| LWT | 异常断线由 broker 代发；keepalive ≤60 s |
| 主题 | `{site}/{line}/{device}/{tag}` 或 `spBv1.0/{group}/DDATA/{node}/{device}` |
| payload | JSON（ts/value/quality）、Sparkplug B（Protobuf）、裸值 |
| Sparkplug | NBIRTH→NDATA/DDATA→NDEATH；seq 0–255 循环，断号即丢包 |

- **接入**：1883/8883/8083；`paho-mqtt`（v2 回调签名与 v1 不兼容）、`tahu`。
- **易错**：① QoS1 重复累加产量；② retained 残留被当实时值；③ 客户端 ID 冲突互踢。

## 5. 三菱 MC（3E）

| 项 | 内容 |
|---|---|
| 帧 | 副标题 5000 + 网络号 + PC 号 + IO 03FF + 站号 + 数据长2 + **监视定时器2（×250 ms）** + 命令2 + 子命令2 + 数据 |
| 命令 | 0401 批量读 / 1401 批量写（子命令 0001 位、0000 字） |
| 软元件 | D/W/R 字；M/X/Y/B 位；**X/Y 十六进制编址**，D/M 十进制 |
| 编码 | 二进制 3E 帧与 ASCII 帧端口不通用 |

- **格式**：全大端；响应 = D000 + … + 数据长 + **结束码（0 才成功）** + 数据。
- **接入**：TCP 5000；`pymcprotocol` 或自写 socket。
- **易错**：① 定时器当毫秒；② X10 传 10 而非 0x10；③ 位点数与字数混算致帧错位。

## 6. 欧姆龙 FINS

| 项 | 内容 |
|---|---|
| 帧 | 10B 头（ICF/RSV/GCT/DA1-3/SA1-3/SID）+ 命令2 + 数据 |
| 命令 | **0101 读 / 0102 写** / 0105 强制置位 / 0401-0403 运行停止 / 0701-0702 时钟 |
| 内存区 | DM=0x82、CIO=0xB0、WR=0xB1、H=0xB2、EM、T/C |
| 传输 | TCP/UDP 9600；TCP 加 FINS/TCP 头握手 |
| 节点号 | 1–254，**同网内必须唯一** |

- **格式**：区码2 + 起始地址2 + 位/字数2；响应 = 结束码2 + 数据。
- **接入**：`pyfins` 或 socket。
- **易错**：① 节点号重复收串包；② 区码传"D"而非 0x82；③ 结束码非 0 仍解析数据。

## 7. REST/HTTP

| 项 | 内容 |
|---|---|
| 鉴权 | Basic / Bearer JWT / API Key / HMAC 签名 / mTLS |
| 分页 | `page/size`、`offset/limit`、`cursor` |
| 限流 | 429 + Retry-After，指数退避 |
| 错误 | HTTP 码 + 业务码；**200 内带失败是常见坑** |
| JSON | `{"timestamp":..,"data":[{"tag":..,"value":..,"quality":"good"}]}` |

- **接入**：80/443；`httpx`/`requests`，推送用 SSE/WebSocket。
- **易错**：① 只看 200 不看业务码；② 忽略分页丢点；③ 时区与秒/毫秒混用。

## 模拟器必须可配置的参数

| 分类 | 参数 |
|---|---|
| 字节序 | float32/int32 的 ABCD/CDAB/BADC/DCBA；IEC104 小端；MC/FINS 大端 |
| 地址 | 基址 0/1；4xxxx 开关；X/Y 十六进制；IOA 3B 从 1；NodeId 前缀与 ns |
| 站号 | Modbus 1–247；FINS 节点号 1–254（唯一性校验）；IEC104 公共地址；MC 网络/PC/站号 |
| 时间 | Modbus 超时与重试；OPC UA SessionTimeout/PublishingInterval；IEC104 t1/t2/t3 与 K/W；MC 定时器 ×250 ms；MQTT keepalive |
| 状态 | 0=停机/1=运行/2=故障（可换映射）；UA StatusCode；IEC104 SIQ 的 IV/NT/SB/BL；MQTT quality |
| 异常注入 | Modbus 异常码 02/03/04；IEC104 丢帧与延迟确认；UA Bad；MQTT 断连触发 LWT |
| 规模 | 单次读上限、点位数、变化频率 |

## 「本机通、现场不通」高风险点

1. **float32 字序**：自环一致，真机数值变天文数字或 0。
2. **地址基址差 1**：全表错位，能读但值全错。
3. **防火墙端口**：502/2404/4840/9600 常被现场策略拦截。
4. **单次读超限**：模拟器宽容，真机回异常 03。
5. **单元标识/从站号**：网关后 unit id 与设备地址不一致，超时但 ping 通。
6. **IEC104 K/W 与 t1**：本机不回确认没事，现场 15 s 断链。
7. **UA 证书与命名空间**：None 可连，现场强制签名 + ns 变化致节点全丢。
8. **MQTT 客户端 ID / retained**：多实例互踢、重启读过期值。
9. **MC 定时器与 FINS 节点号**：定时器设小超时；节点冲突收他人应答。
10. **时区与时间戳**：UTC/本地混用，趋势错位、报警时序乱。
11. **位/字点数语义**：长度字段算错整帧报废。
12. **断线重连**：本机不测，现场订阅/会话未重建致假在线。
