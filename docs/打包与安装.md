# 打包与安装

Windows 安装包（`SCADA-Setup-<版本>.exe`）的构建、安装、卸载与验证。

---

## 一、整体流程

```
源码
 │  build.py（PyInstaller）
 ▼
dist-scada-<VERSION>\SCADA.exe        绿色版（可直接解压运行）
 │  installer\scada.iss（Inno Setup 6）
 ▼
dist-installer\SCADA-Setup-<VERSION>.exe      安装包
 │  installer\verify_install.ps1
 ▼
安装 → 检查 → 卸载 → 检查残留
```

两步分离的好处：**绿色版单独可用**。现场不允许装软件时，直接拷
`dist-scada-<VERSION>` 目录也能跑；需要正式部署时才用安装包。

---

## 二、构建

### 2.1 准备

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | 3.10+ | 项目 venv 即可 |
| PyInstaller | 最新 | `build.py` 会自动 `pip install` |
| Inno Setup | 6.x | 只有出安装包才需要 |

装 Inno Setup：

```powershell
winget install -e --id JRSoftware.InnoSetup
# 或 https://jrsoftware.org/isdl.php
```

### 2.2 一条命令

```powershell
powershell -ExecutionPolicy Bypass -File installer\build_installer.ps1
```

输出：

```
dist-installer\SCADA-Setup-1.3.1091.exe
dist-installer\SCADA-Setup-1.3.1091.manifest.json   ← 版本/大小/SHA256
```

### 2.3 常用参数

```powershell
# 只改了 .iss，复用已有 PyInstaller 产物（快）
... build_installer.ps1 -SkipPyInstaller

# 先清掉同版本旧安装包
... build_installer.ps1 -Clean
```

### 2.4 没装 Inno 会怎样

脚本**不会静默跳过** —— 打印安装命令并以退出码 `2` 结束。
这是故意的：CI 里「构建成功但没有安装包」是最难发现的假绿。

## 三、安装流程（用户看到什么）

1. **语言**：简体中文
2. **许可/欢迎** → 下一步
3. **选择安装位置**（默认 `C:\Program Files\SCADA`，可改）
4. **附加任务**（勾选框）：
   - 创建桌面快捷方式（默认勾选）
   - 创建快速启动栏快捷方式（默认不勾）
   - 开机自动启动（默认不勾）
   - 添加 Windows 防火墙入站规则（默认勾选，端口 5000/5001）
5. **开始菜单文件夹**（默认 `SCADA`）
6. **安装** → 进度条 + 写日志
7. **完成页**：可勾选「立即启动」

### 安装日志

默认开启（`SetupLogging=yes`），位置：

```
%TEMP%\Setup Log <时间>.txt
```

也可显式指定：

```powershell
SCADA-Setup-1.3.1091.exe /LOG="D:\install.log"
```

### 装了什么

| 位置 | 内容 |
|---|---|
| `{app}\` | 程序文件、`SCADA.exe`、`.env`、`配置\`、`模板\`、`静态资源\` |
| `{app}\unins000.exe` | 卸载程序 |
| 开始菜单 `SCADA\` | 程序 / 安装说明 / 卸载 |
| 桌面 | 快捷方式（勾选时） |
| `HKLM\Software\SCADA` | `InstallPath` / `Version` |
| `HKCU\...\Run` | 开机自启项（勾选时） |
| 防火墙 | 规则 `SCADA Web`（勾选时） |

> **数据目录不在安装目录之外**。`data\`、`logs\`、`exports\` 都在 `{app}` 下 ——
> 卸载时按用户选择处理（见下节），不会散落在 `%APPDATA%` 里找不到。

## 四、卸载（重点）

### 4.1 交互卸载

从「应用和功能」或开始菜单「卸载 SCADA」启动，走完向导后会**问一句**：

```
是否同时删除运行数据？

包括：数据库（历史数据与报警记录）、运行日志、导出文件。
如果这台机器以后还要重装、或需要保留历史数据做追溯，请选「否」。

默认不删除（程序文件、快捷方式、注册表项无论如何都会清理干净）。
```

默认按钮是**「否」** —— 误删现场数据的代价远高于多留一个目录。

### 4.2 无条件清理的部分

不管选「是」还是「否」，以下**一定**被清理：

- 安装目录下所有程序文件（`SCADA.exe`、`_internal\`、`.dll`）
- 开始菜单文件夹与快捷方式
- 桌面 / 快速启动栏快捷方式
- `HKLM\Software\SCADA`（`uninsdeletekey`）
- `HKCU\...\Run` 自启项（`uninsdeletevalue`）
- 卸载项（「应用和功能」里的条目）
- 防火墙规则 `SCADA Web`
- 运行中的进程（`taskkill /F`，卸载第一步）
- 缓存类：`__pycache__`、`.pytest_cache`、`*.pyc`、`stdout.txt`/`stderr.txt`

### 4.3 按选择处理的部分

`data\`、`logs\`、`exports\`、`backups\`

卸载结束时会**报告**保留了哪些目录，不会「看起来干净、其实留了一堆」。

### 4.4 静默卸载

```powershell
# 保留数据（默认，安全方向）
& "$env:ProgramFiles\SCADA\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES

# 连数据一起删（完全干净）
& "$env:ProgramFiles\SCADA\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /DELETE-DATA
```

静默模式下**不弹窗**（否则自动化脚本会卡死）。要删数据必须显式传
`/DELETE-DATA`。

## 五、验证安装与卸载

```powershell
# 默认：验证「保留数据」路径
powershell -ExecutionPolicy Bypass -File installer\verify_install.ps1

# 验证「完全干净」路径
... verify_install.ps1 -DeleteData

# 指定安装包 / 安装目录
... verify_install.ps1 -SetupExe D:\SCADA-Setup-1.3.1091.exe -InstallDir D:\test\scada
```

脚本做的事：

1. **静默安装**到临时目录（默认 `%TEMP%\SCADA-verify-<时间戳>`，不污染 Program Files）
2. **安装后逐项检查**：
   - 主程序、卸载程序存在
   - 安装日志已生成
   - 开始菜单文件夹与快捷方式
   - 注册表 `InstallPath` / `Version` 值正确
   - 「应用和功能」里有条目且显示名含版本
3. **造一点运行数据**（`data\`/`logs\`/`exports\` 各放一个标记文件）
4. **静默卸载**
5. **卸载后检查残留**：
   - 程序文件全删（`*.exe` 数量为 0）
   - 开始菜单、注册表、卸载项、防火墙规则都清了
   - 数据目录：加了 `-DeleteData` 则必须消失，没加则必须保留

退出码 `0` = 全过；`1` = 有失败项（会打印实际状态与日志路径）。

### 手工验证清单（没有脚本时）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 双击安装包 | 中文向导出现 |
| 2 | 改安装路径到 `D:\SCADA` | 装到该目录 |
| 3 | 装完看开始菜单 | 有「SCADA」「安装说明」「卸载 SCADA」 |
| 4 | 双击桌面图标 | 浏览器打开 `http://127.0.0.1:5000`（或 5001） |
| 5 | 看 `%TEMP%\Setup Log*.txt` | 有完整安装日志 |
| 6 | 「应用和功能」里搜 SCADA | 有条目，显示版本号 |
| 7 | 卸载，选「否」保留数据 | 程序没了，`data\` 还在 |
| 8 | 再装一次，卸载选「是」 | `data\` 也删了 |
| 9 | 检查 `HKLM\Software\SCADA` | 已消失 |
| 10 | 检查防火墙规则 | `SCADA Web` 已消失 |

## 六、常见问题

**Q：覆盖安装时提示「文件正在使用」**
A：`CloseApplications=yes` 会让安装程序自动检测并尝试关闭。若仍有残留，
先手动退出 `SCADA.exe`（托盘/任务管理器），再重试。

**Q：安装包被 SmartScreen 拦截**
A：未签名的 exe 都会。生产发布建议购买代码签名证书并对
`SCADA.exe` 与 `SCADA-Setup-*.exe` 都签名：

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a <文件>
```

**Q：装完启动，浏览器打不开**
A：① 看是否被杀软拦了端口；② 检查 `%TEMP%\Setup Log` 与 `{app}\logs\`；
③ 手动跑 `{app}\SCADA.exe` 看控制台报错；④ 确认 5000/5001 没被占用：

```powershell
netstat -ano | findstr ":5000 :5001"
```

**Q：卸载后目录还在**
A：这是**预期**（保留了 `data\`/`logs\`）。卸载结束时会弹窗列出保留的目录。
要完全删干净：卸载时选「是」，或加 `/DELETE-DATA`。

**Q：能装到非系统盘吗**
A：可以，向导第 3 步改路径。注意 `data\` 会跟着走 —— 历史数据量大时建议
装到数据盘。

**Q：现场不允许装软件**
A：直接用绿色版：把 `dist-scada-<VERSION>\` 整个目录拷过去，双击 `SCADA.exe`。
它会在同目录建 `data\`/`logs\`/`exports\`，不需要管理员权限。

## 八、实测记录（2026-11-03）

构建机：Windows 11 / Python 3.13 / PyInstaller 6.22.3 / Inno Setup 6.7.3

```
dist-scada-1.3.1091\SCADA.exe              产物
dist-installer\SCADA-Setup-1.3.1091.exe    51.1 MB
```

| 验证 | 结果 |
|---|---|
| `verify_install.ps1`（保留数据） | **20/20 通过** |
| `verify_install.ps1 -DeleteData`（完全干净） | **20/20 通过** |

覆盖：安装退出码、主程序、卸载程序、安装日志、开始菜单、注册表
（InstallPath / Version）、「应用和功能」条目（含版本）、数据保留/删除、
程序文件清理、注册表清理、卸载项移除、防火墙规则删除。

### 构建时踩到的四个坑（都已在脚本里修掉）

**1. Inno Setup 6.7.3 不带简体中文语言包**

安装目录的 `Languages` 里只有日/韩/德/法，中文在官方仓库的 `Unofficial/` 下。
写 `compiler:Languages\ChineseSimplified.isl` 会在别人机器上直接编译失败：

```
Couldn't open include file "...\Languages\ChineseSimplified.isl"
```

→ 语言包**内置**到 `installer/lang/`（20 KB），任何装了 Inno 6.4+ 的机器都能构建。

**2. `[Icons]` 不支持 `skipifsourcedoesntexist`**

那是 `[Files]` 的 flag。写进 `[Icons]` 报
`Parameter "Flags" includes an unknown flag`。
→ 改用 `Check: FileExists(...)`；顺带把 `.md` 改成用记事本打开
（`.md` 不一定有文件关联，`shellexec` 又是 `[Run]` 的 flag）。

**3. PowerShell 5.1 读 UTF-8 无 BOM 的脚本会乱码**

中文全变成 `浜х墿鐩綍`，然后报一堆假的语法错误（缺右括号、字符串未终止）。
→ 两个脚本都存成 **UTF-8 with BOM**；`.iss` 同样加 BOM（Inno 也认）。

**4. 非管理员机器装不上（`PrivilegesRequired=admin` 会弹 UAC）**

CI 和普通开发机都跑不起提权。
→ 加 `PrivilegesRequiredOverridesAllowed=commandline`，注册表根改 `HKA`
（自动跟随 HKLM/HKCU），验证脚本用 `/CURRENTUSER` 安装。
管理员场景与普通用户场景**卸载逻辑完全一致**，只是落盘位置不同。

### 验证脚本自己的一个 bug

第一版用 `DisplayName -like '*SCADA*'` 找卸载项 —— 结果匹配到了机器上另一个
**`SmartSCADA 1.3.1079`**，于是「卸载项已移除」永远红。

→ 改成按 `AppVerName` 精确匹配，并让 `.iss` 的 `UninstallDisplayName`
带上版本（同时装多个版本时能分清该卸哪个）。

### 另一条经验

在 Git Bash 里用 heredoc 改 Windows 路径会踩 MSYS 的路径转换：
`'HKLM:\Software\SCADA'` 被改写成 `'HKLM://Software//SCADA'`，
而报错信息里看不出来（字符串看起来只是多了几个斜杠）。

→ 改含反斜杠的脚本时，用编辑器/Write 工具，或 `chr(92)` 拼，
不要直接在 bash heredoc 里写字面反斜杠。
