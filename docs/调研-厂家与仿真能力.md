# 调研：厂家产品与官方仿真能力

> 本文件由调研生成，用于判断「模拟器该复刻哪些真实型号的点表」以及
> 「能不能直接用厂家仿真器代替自研模拟」。

## 一、核心结论（先说最重要的）

**厂家官方仿真器几乎都不能对外提供 Modbus / OPC UA 服务端。**

它们的设计目的是「在 IDE 内部验证 PLC 程序逻辑」，不是「给 SCADA 供数据」：

| 仿真器 | 能否被外部 SCADA 连上 |
|---|---|
| 西门子 PLCSIM / PLCSIM Advanced | Advanced 支持 API 级联（仿真多台 PLC 互联），但**不提供 Modbus 从站**；OPC UA 需额外配置且授权受限 |
| 三菱 GX Works3 仿真 | 仅 IDE 内部，**不监听任何端口** |
| 欧姆龙 Sysmac 仿真 | 仅 IDE 内部 |
| 罗克韦尔 Studio 5000 Emulate | 仅 IDE 内部（EtherNet/IP 有限） |
| 发那科 ROBOGUIDE / 库卡 OfficeLite | 机器人本体仿真，**不开放现场总线** |
| **优傲 URSim** | **例外**：免费，提供 Modbus TCP 服务端 + RTDE + 示教器，可被外部连 |
| ABB Drive composer | 部分：变频器参数仿真，Modbus 有限 |

**因此：自研模拟器 + 按真实点表复刻，是唯一可行路线。** 官方仿真器只能
用来「验证 PLC 程序写得对不对」，不能用来「给上位机供数据」。

## 三、对接/模拟优先级

按「国内现场占有率 × 协议公开度 × 模拟可行性」排序：

| 优先级 | 厂家型号 | 理由 |
|---|---|---|
| **P0** | 汇川 H5U、台达 DVP、施耐德 M340 | 国产中小产线主力，Modbus 点表全公开，最容易做「像真的」 |
| **P0** | ABB ACS580 / PSTX、华为 SUN2000 | 变频器与光伏是当前增量最大的两块，寄存器表官网可下 |
| **P1** | 三菱 FX5U（MC）、欧姆龙 NJ（FINS） | 协议已在项目里实现，点表公开；日系设备在 3C/汽车零部件多 |
| **P1** | 西门子 S7-1500（S7comm / OPC UA） | 高端产线标配，但 S7 协议需 snap7，点表要组态导出 |
| **P2** | 中控 JX-300XP、和利时 LK | DCS 点表按项目交付，公开资料少；模拟需按典型化工点表造 |
| **P2** | 图尔克 IO-Link、E+H/罗斯蒙特/横河仪表 | 点表公开但点位少，模拟价值主要在「量纲正确」 |
| **P3** | 发那科/库卡/罗克韦尔 | 协议封闭、仿真器付费且不开放总线，投入产出比低 |

## 四、对模拟器的直接启示

1. **优先复刻「点表公开」的型号**（汇川/台达/施耐德/ABB/华为）——
   模拟出来的地址与量纲能直接对照官方手册，验收时说得清。
2. **状态字编码必须按厂家手册**：汇川/台达常用 `0=停机 1=运行 2=故障`，
   三菱 MC 的 `X/Y` 是位软元件、`D` 是字软元件，不能混。
3. **不要指望买仿真器解决模拟问题** —— 除 URSim 外都不对外暴露协议。
