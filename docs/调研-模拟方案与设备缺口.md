## 二、模拟深度分级

| 等级 | 适用设备 | 理由 |
|---|---|---|
| L3 物理耦合+故障传播 | 冷却塔、锅炉给水泵、除尘风机、空压总管、模温机、曝气池、UPS电池组、消防泵 | 存在明确守恒式或联锁链，故障会跨设备传播，是"看起来真"的关键 |
| L2 一阶惯性 | 数控车床、冲压机、堆垛机、柴发、汇流箱、充电桩 | 单机为主，惯性+刀具/模具寿命曲线即可，无跨设备守恒 |
| L1 随机噪声 | 指示灯、按钮、门禁、就地仪表 | 无过程量，只需状态位 |

## 三、当前模拟器的真实度短板（方法层面）

1. **缺日周期/班次周期**：负荷、用气、用电、光伏辐照、曝气DO、产量均应按 24h 基线 + 三班阶跃（8:00 爬坡、12:00 午休谷、夜班 60% 负荷）生成，而非全天同均值正弦。
2. **该离散的量用了连续函数**：产量计数、批次号、状态位（运行/待机/报警）、阀门开关、换模换刀、AGV任务态，应为事件驱动/泊松到达的阶跃序列。
3. **缺守恒约束**：进料=出料+在制品变化；P=ΣPφ 且 S²=P²+Q²；产气=用气+泄漏+储罐压降；总电表=分表之和(±1%)；良品+废品=投入。
4. **故障多为瞬间跳变**：轴承振动/温度、刀具磨损、滤袋压差、电池内阻、换热器结垢应走随机游走 + 加速模型（Arrhenius / 逆幂律），再叠加突变型故障。

## 四、可参考标准（提供合法取值范围）

| 标准 | 给模拟器提供什么 |
|---|---|
| ISA-95 / ISA-88 状态模型 | 设备状态合法集与迁移（Idle/Running/Held/Stopped/Aborted），替代布尔开关 |
| OEE 六大损失 | 停机原因码、速度损失、废品率的分解口径与停机时长分布 |
| ISO 10816-3 | 振动烈度 RMS 分级：A<2.8、B 2.8–4.5、C 4.5–7.1（报警）、D>7.1 mm/s（停机） |
| GB/T 12325 | 三相供电电压偏差 ±7%、单相 +7%/−10%，约束电压模拟范围 |
| GB 13223 | 烟尘30、SO₂100、NOx100 mg/m³，作为 CEMS 限值与超标报警阈值 |
| IEC 60034-1 | 电机温升限值（B级80K/F级105K），约束绕组温度上限与热保护动作点 |
